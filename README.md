## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That copies `entry.png` (1024×1024, under 1 MiB) to the output directory
as `entry.png`. Deterministic: the same bytes on every run, no network.
